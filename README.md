# Ocean View Hotel Website

## Project Description

This project is a clean, responsive, and professional website designed for a school named Ocean View. The website serves parents and students with clear navigation and practical content sections including home, about, admissions, and contact pages. The focus is on providing an informative, accessible experience without unnecessary complexity or gimmicks.

## Tech Stack

- HTML5
- CSS3 (Flexbox-based layout)
- Vanilla JavaScript (minimal, used for mobile menu toggle)

## Local Development

To run the website locally:

1. Clone the repository:

   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:

   ```
   cd ocean-view-hotel-website
   ```
3. Open `index.html` in a web browser to view the site.

No build tools or dependencies are required.

## Deployment

This project can be deployed using GitHub Pages by:

1. Pushing the code to a GitHub repository.
2. Going to the repository settings.
3. Enabling GitHub Pages from the `main` or `master` branch root.
4. Accessing the website via the provided GitHub Pages URL.

## Folder Structure
